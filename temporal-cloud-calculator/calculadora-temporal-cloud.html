Cómo se cuenta

Cada paso: veces × (% camino / 100) × Actions unitarias. Activity = 1 schedule + retries + heartbeats que llegan al server (el SDK limita al 80% del Heartbeat Timeout). Replay no factura.
Child Workflow: 2 Actions en el padre si el hijo no está como fila propia. Si el hijo está listado, pon origen del hijo = Cliente y no dupliques el start. Schedule: 3 Actions (incluye el start).

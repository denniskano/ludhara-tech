Cómo se cuenta

Actions: veces × (% camino / 100) × unidad. Activity = 1 schedule + retries + heartbeats que llegan al server. Replay no factura.
Event History (KB) = Payload StartWorkflow + Σ (veces × % × Payload del mensaje × copias en history). Activity persiste input + result (×2) y cada retry vuelve a persistir. Query y Timer no suman Payload al Event History.
Child Workflow: 2 Actions en el padre si el hijo no está como fila propia. Si el hijo está listado, pon origen del hijo = Cliente y no dupliques el start. Schedule: 3 Actions (incluye el start). Un solo namespace → un Retention Period.
